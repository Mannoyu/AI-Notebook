# 离线笔记助手：功能规范

状态：首版规格，待评审。本文定义产品行为和验收标准；[技术设计](plan.md)说明如何实现，[实施任务](tasks.md)说明先做什么。

## 目标与范围

用户在自己的 Windows 电脑上通过 Ego 浏览器访问普通网页，编写或导入笔记。即使不下载模型，网页也能作为本地笔记工具使用。用户可自愿下载端侧模型，在浏览器内得到总结和补充。离线资源准备完成后，断网重启浏览器并访问同一网址，已准备好的功能仍可用。

首版不包含英语、语音、出题、文件夹、标签、全文搜索、富文本或实时双栏编辑、PDF/Word 导入、批量备份与恢复、账号、云同步、云推理及 App 安装入口。Chrome、Edge 和移动端不在首版验收范围。

## 功能需求

| 编号 | 需求 |
| --- | --- |
| FR-01 | 用户可新建、改名、删除、编辑和粘贴笔记。列表按最近编辑排序，编辑自动保存；只有保存成功才显示已保存。 |
| FR-02 | `.txt` 和 `.md` 文件在本地导入为独立笔记，不覆盖已有笔记。支持 UTF-8；无法读取或不支持的文件给出提示，不生成残缺笔记。 |
| FR-03 | 编辑器支持「编辑 / 预览」切换，Markdown 源码不因预览而改变；总结和补充按 Markdown 展示。预览不执行原始 HTML，不自动请求远程媒体。 |
| FR-04 | 支持单篇 `.md` 导出供外部阅读，包含标题、当前原文和可用的总结、补充。旧分析随文件标注为基于修改前的笔记；没有分析时仍可导出原文。导出不是恢复格式。 |
| FR-05 | 下载前检查浏览器推理能力、设备适配器及可估算的存储空间。初筛不通过时提示原因、不开始下载；通过后展示预计大小，由用户主动选择。跳过、下载失败或试跑失败均不影响笔记功能。 |
| FR-06 | 下载时显示进度；本地推理试跑成功且必要文件可从本地读回后，才显示「离线模型已就绪」。缓存缺失时给出提示，不自动联网重下。 |
| FR-07 | 用户手动分析非空笔记。总结忠实于原文；补充与总结分开，允许有限拓展，并标明为模型补充、未经联网核验。 |
| FR-08 | 输入超出单轮预算时，按原文顺序做滚动摘要：已有摘要加下一段原文，逐轮压缩。显示分段进度，保留完整原文；读完后只生成一次补充，不提交半成品。 |
| FR-09 | 编辑正文后保留上次成功的分析，并提示「基于修改前的笔记」。不自动重跑；重新分析失败不覆盖旧结果。 |
| FR-10 | 宽屏编辑页左侧是笔记，右侧常驻 AI 分析；窄屏上下排列。分析过程中即时显示阶段，模型输出正文后逐步显示总结和补充，不展示推理过程。切换笔记不串稿，未完成的草稿不保存、不导出。 |

## 非功能需求

| 编号 | 需求 |
| --- | --- |
| NFR-01 | 不上传笔记、导入文件、推理输入或结果。笔记和结果仅持久化在当前浏览器配置、当前站点下；不承诺清除站点数据后可恢复。 |
| NFR-02 | 网页资源准备完成后，即使没下载模型，也能断网重启浏览器并在同一网址使用笔记功能。模型另行就绪后，还须能离线分析新笔记；无云端回退。 |
| NFR-03 | 分析期间可继续编辑，模型加载或推理失败不得造成笔记丢失，存储失败不得显示为已保存。 |

## 验收用例

| 编号 | 关联需求 | 操作与预期 |
| --- | --- | --- |
| AC-01 | FR-01、FR-02、NFR-02 | 不下载模型；新建并保存笔记，分别导入 UTF-8 `.txt`、`.md`。断网退出所有 Ego 窗口并重启，在同一网址确认内容、改名和最近编辑顺序保留；删除一篇后再刷新，确认不会恢复。导入不支持的文件无新增记录。 |
| AC-02 | FR-03、FR-04 | 用含标题、列表、代码块、原始 HTML 和远程图片的笔记切换预览；源码不变，不执行 HTML、不请求图片。分别导出无分析、当前分析和旧分析的笔记，在外部 Markdown 阅读器检查对应内容和旧版提示。 |
| AC-03 | FR-05、FR-06 | 覆盖 WebGPU 不可用、空间明确不足、可下载但用户跳过、下载中断、下载后试跑失败和成功。验证同意前无模型文件请求，失败或跳过不阻断记笔记，成功前不显示就绪。 |
| AC-04 | FR-06、FR-07、NFR-01、NFR-02 | 在目标 Ego 上同意下载并试跑。断开系统网络，完整退出并重启浏览器，打开同一网址，找回笔记并创建、分析一篇新笔记。验证总结、补充分开且可保存回读；在联网运行同一流程时检查网络日志，无笔记内容或分析结果外传。 |
| AC-05 | FR-08、FR-09、NFR-03 | 用超出单轮预算且首、中、尾都有已知要点的文本触发多轮分析，检查各段按序被处理、补充只调用一次、原文保持完整。编辑后旧结果标记过时；模拟处理中途失败，旧结果仍在，保存失败有明确提示。 |
| AC-06 | FR-09、NFR-03 | 启动分析后继续编辑；任务成功后结果仍绑定启动时的正文版本并显示过时。分析期间删除笔记，任务结束也不得恢复记录。 |
| AC-07 | FR-06、NFR-02 | 仅清除模型缓存，保留网页缓存和笔记，断网重开。模型不显示就绪，不自动下载；已有笔记和分析仍可读写或导出。 |
| AC-08 | FR-10 | 在宽屏打开笔记，确认两个面板并排且分析无需展开。在 Ego 中分析一篇笔记，确认完成前能看到正文逐步增长，并在补充阶段继续显示总结。刷新后可回读完整结果；缩窄视口后面板上下排列且无横向溢出。 |

首版通过标准：功能与离线用例在用户指定 Windows 电脑上的 Ego 浏览器通过。只有纯笔记功能可用不算通过离线 AI 验收。
