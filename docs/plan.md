# 离线笔记助手：技术设计

状态：架构初选；与[功能规范](spec.md)一同评审。模型参数和设备表现须经实测，不把上游示例行为当作本项目的实测结论。

## 技术架构

| 边界 | 选型与职责 |
| --- | --- |
| 在线入口 | Next.js App Router、React、TypeScript。Next.js 提供网页入口和不含用户数据的公开模型清单；编辑、分析、导入导出不调用服务端业务接口。 |
| 浏览器 UI | 单网页工作区：最近编辑列表、编辑/预览、分析与下载状态。核心路径不依赖联网路由切换、Server Actions 或在线 API。 |
| 笔记存储 | IndexedDB；原文和分析结果采用结构化记录并做版本化迁移，与可重建的缓存分离。 |
| 推理 | Web Worker 中运行 Transformers.js + WebGPU，以用户提供的 [DeepSeek-R1 WebGPU 示例](https://github.com/huggingface/transformers.js-examples/tree/main/deepseek-r1-webgpu) 为基线。 |
| 离线资源 | Service Worker 缓存生产构建的网页壳、入口、JS/CSS、Worker 及其运行时资源；模型优先复用 Transformers.js 的浏览器缓存。无安装入口。 |

## 数据与状态契约

- `Note`：`id`、`title`、`body`、`bodyRevision`、`createdAt`、`updatedAt`。正文提交变化时递增 `bodyRevision`；修改标题更新排序时间，但不让基于正文的分析失效。
- `Analysis`：`noteId`、`sourceRevision`、`summaryMarkdown`、`supplementsMarkdown`、`modelRevision`、`createdAt`。每篇仅保存最近一次成功结果；`sourceRevision` 与当前 `bodyRevision` 不同即为过时。提交结果时验证笔记仍存在；删除笔记与删除关联结果在同一事务中完成。
- `ModelManifest`：固定模型标识、不可变版本、下载来源、预计下载字节数。在线入口提供清单，当前部署所需清单随离线网页资源保存；本地检查和分析不得强制联机刷新清单。
- Worker 请求使用 `requestId` 匹配响应。分析任务接收正文快照，返回分段进度、可见文本草稿和最终结果或失败状态。`TextStreamer` 过滤推理标记后分批发送当前阶段的累计文本；新的分段替换上一段草稿，补充阶段保留最终总结。并发限制为一个推理任务；界面按笔记 ID 和启动时的正文版本关联草稿，只有最终结果进入本地存储。
- UI 分别维护网页离线状态、笔记保存状态和 AI 状态。AI 状态为检测中、不可用、可下载、下载中、试跑中、就绪或失败；重开后按本地资源和实际加载结果复核，不信任单独的「已下载」标记。

## 关键流程

1. **检测与下载**：在安全上下文检查 WebGPU、适配器、浏览器存储及已知模型要求。可用空间是估算，不能证明显存或内存足够；预检通过不等于可运行。首次真实推理验证在用户明确同意下载后进行。后续分析采用仅本地加载路径，缺文件时报错而非联网补齐。
2. **离线重开**：在固定安全来源（HTTPS 或受支持的 localhost）测试生产构建。离线网页资源准备完成后，导航回同一网址可命中缓存；配套运行时资源不得临时从 CDN 获取。发布更新时仅当新壳资源完整才切换缓存，不以更新或缓存清理为由清空 IndexedDB。
3. **滚动摘要与结构化分析**：单轮总预算 2560 token，按实际 tokenizer 计算对话模板、提示词、前段要点、当前分片和预留输出。极短备忘仅提炼事项；长笔记先按段落压缩，再做最终分析。压缩上限 512 token，常规总结和补充各最多 1280 token，含不对用户展示的推理过程。补充最多生成一次，优先用来源资料，必要时改用总结或缩减生成预算。所有阶段成功后才一起写入；滚动压缩可能丢失细节。
4. **预览与导出**：统一 Markdown 渲染策略，禁用原始 HTML 和自动加载远程媒体，限制链接协议。导出在浏览器生成 UTF-8 `.md`；原文保留在独立区段，旧版提示紧邻分析标题。

## 验证门槛

先在目标 Windows 的 Ego 上，以 Next.js 生产构建验证最薄闭环：记一篇笔记、征得同意后下载并试跑、断网退出并重开、恢复笔记、分析新笔记。记录 Ego 版本、WebGPU 适配情况、解析出的模型版本与量化、资源字节数、加载/推理耗时和关键缓存命中情况。再据实确定 token 预算、模型空间余量和是否需要自管模型缓存。若未通过，先定位网页缓存、推理资源、模型缓存或硬件能力，不以云端回退绕过规格。
